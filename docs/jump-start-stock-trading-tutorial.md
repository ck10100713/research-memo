## 一句話摘要

寫給「**從未碰過股票交易研究的控制論學者**」的入門 tutorial，由 control + finance 跨界的五位學者合寫，把交易研究的核心問題、常用建模方法、未解難題系統性整理給控制社群入門。

## 推測重點（根據 tutorial 性質與作者背景）

由於 IEEE Xplore 需訂閱才能完整下載，下列為依作者群與會議定位的合理推測：

1. **問題設定**：把股票交易包成 control system 框架（state、input、output、feedback）。
2. **常見方法**：affine feedback、Kelly betting、log-optimal、drawdown modulation、DLP 等系列招式整理。
3. **常用資產類別**：stock、ETF、crypto。
4. **常見陷阱**：survivability、bankruptcy、execution delay、transaction cost。
5. **Open problems**：含成本下的最佳頻率、distribution-free robust trading、deep learning 與 control 結合等。

## 研究價值與啟示

### 關鍵洞察

1. **「Tutorial 在頂級會議發表」是學術社群橋接的標準動作**：CDC 不常開 tutorial 軌，能上 = 表示主辦方認可這條跨界主題夠成熟、夠值得吸引新血。
2. **作者群配置很策略**：Barmish（control + finance 老牌）、Formentin（system identification + finance）、Hsieh（DLP 系列）、Proskurnikov（network control）、Warnick（control theory 教育推手）── 跨領域 + 跨世代，目標是把「stock trading research」當作 control 社群的下一塊新領域開拓。
3. **Tutorial 是進入文獻的最快路徑**：對想了解這條 control × finance 路線的初學者，這篇是最佳起點，比讀 30 篇 paper 高效。
4. **與 Hsieh 整條研究線互引**：本篇引用作者過去所有 DLP / drawdown / log-optimal 工作 ── 等於是把整個 publication record 包裝成教學素材。

### 與其他研究筆記的關聯

整條 Hsieh 研究線（Section 1 全部 17 篇 + Section 2/3）都是這篇 tutorial 的引用素材。本篇可視為**這條 publication 路線的官方入口**。
